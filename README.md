# Plugin-Autocad
Este script desarrollado (y basado en uno que ya existe) automatiza la creación de detalles ampliados (callouts) en AutoCAD a partir de un área específica del dibujo. Es una herramienta ideal para arquitectos, ingenieros y dibujantes que necesitan extraer, escalar y etiquetar detalles constructivos de manera rápida y ordenada.
